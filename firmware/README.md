# firmware

Official OS files go here: download, unzip, and drop the `.syx` in this folder, or add it on the page. They are Elektron's and
are not part of the repository.

The page lists every file the firmware tool validates. The emulator runs the ones it has an address profile for:
Digitakt II OS 1.16 for now. 1.17 can be inspected and built, but no mod is made for it yet.
